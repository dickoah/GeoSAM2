Fill unassigned

Grey means no evidence, never a part: every unassigned face takes a label from its neighbours along the surface, or through the thickness where no view saw it. The result is a label file the split can take.
5

Split

Cuts the mesh along the label boundaries, one mesh per part, straight from the label file. Mode sdf puts boundaries inside triangles and needs the mesh's UVs; faces leaves them on existing edges and needs none.
